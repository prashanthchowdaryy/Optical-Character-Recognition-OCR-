# Optical Character Recognition (OCR)

This project demonstrates how to extract text from images using Python and Tesseract OCR.

It shows how images can be processed and converted into readable text using computer vision techniques.

---

## Features

* Extract text from images
* Uses Tesseract OCR
* Simple and easy to understand
* Works with image inputs
* Notebook-based implementation

---

## Tech Stack

* Python
* OpenCV
* pytesseract
* NumPy
* Jupyter Notebook

---

## Project Structure

* pytesseract.ipynb
* images.jpg
* 7.png

---

## Installation

Install dependencies:

pip install pytesseract opencv-python numpy

Install Tesseract OCR:

Download from official site and add it to system PATH.

---

## Usage

Open the notebook:

jupyter notebook

Run all cells to:

* Load image
* Process image
* Extract text

---

## How It Works

* Image is loaded
* Preprocessing is applied
* Tesseract extracts text
* Output is displayed
